# 包说明  
stm32的虚拟串口对于上位机来说都是一样的，也就是说你下位机可以开普通串口也可以开usb虚拟串口，上位机这个节点核心都是通过serial的io库去打开串口硬件的  
使用普通串口记得波特率和上位机要对应（如果要传输的数据量多且频繁，建议开高一点波特率）  
使用usb虚拟串口其实就无所谓波特率，因为速率都是按照usb的速率来的  

这个包可以作为一个中转节点，在这里订阅你的上位机算法数据，然后下发到硬件下位机  


# 应用说明  
建议不同类型的数据（尤指数据来源频率不一样的数据）采用不同id的包来下发  
也就是说： （假如）
1. 底盘速度指令（50hz）
2. 雷达里程计（500hz）
3. 状态标志位（很低频，只在某些阶段触发）

这个时候就可以给每种数据使用不同的包ID，下位机解包时，按照不同的包ID去解析，避免说强行按照高频的数据频率来发包，比如说你将所有数据赛到一帧中，使用雷达里程计的数据频率下发，那么你的底盘速度指令将会是被以零阶保持的形式插值到500hz（这并不是我们想看到的）  

## 协议定义  
推荐按照2包头 + 包ID + CRC + 2包尾的形式来定义协议
